# 試し場（lab/）→ 本番（layer/）への引き継ぎ

企画チャットで作った「3Dの見た目」の試作です。実装チャットはこれを読んで、本番 `layer/index.html` に取り込んでください。
試し場は https://denmochan.github.io/dungeon/lab/ で動きます（保存データは `lab1_` 付きで本番と分けてあります）。

## 決まった方針（本人確認済み）

- **一番いい要素に全体を合わせる**：基準は3Dのゴブリン（丸い形・黒い輪郭線・3段のアニメ塗り）
- **絵柄をそろえるのが最優先**：リアルさやザラザラした質感は入れない（本人「きもい」）
- **壁は「新・岩の塊」**：丸くふくらんだ岩の積み重なり。線は細く、ぼかして、途切れさせる。天井・床も同じ描き方（床は線なし・色むらだけ）
- **壁と天井のつなぎ目は丸める**（天井が「ふた」に見えないように）
- **小物・魔物もゴブリンと同じ描き方**（トゥーン＋輪郭線、丸い形）
- **看板はいらない**
- **鉱石（水晶の群れ）は多すぎる**ので減らす

## 取り込むときの注意

- **看板**：タップで部屋の画面を開く入口でもある。消すなら、部屋の画面をどこから開くか（画面のボタンなど）を先に決めること
- **水晶を減らす**：試し場は見た目だけ間引いている。当たり判定（R.G）はそのまま。本番では部屋の中身を作る所で数を減らすこと
- **重さ**：魔物1種類で約300KB。種族が増える前に形を軽くする作業が要る
- **魔物の3D**：このセーブにいた3種類だけ。ほかの種族はまだ2Dの絵

## 魔物を3Dにする手順（`lab/tools/`）

1. リポジトリの一番上で `python3 -m http.server 8777` を起動する
2. `cd lab/tools && python3 extract2.py <種族名>` を実行する（ゲームの形をそのまま3Dの網にする）
3. `python3 skin2.py <種族名> && gzip -9 ../mon_<種族名>.bin` を実行する（骨と重みをつける）
4. `index.html` の `MON3` に種族名を足す

- 必要なもの：Playwright、Chrome（`--use-angle=swiftshader`）、scikit-image
- 人の形の種族（goblin・skeleton・orc・kobold・imp・golem・human）は、このままで動く
- 形のちがう種族（狼・コウモリなど）は、スライムのように動かし方を個別に作る必要がある
