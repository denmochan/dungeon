### 2. 戦闘のポーズ：`window.__labPose(種族, 状態, k, {side, t})`
- 戻り値は `{R, root}`
  - `R`：いつものリグ（`rigSp24` と同じ形）
  - `root`：体ごと動かす量 `{dx, dy, dz, pitch, roll}`。足もと中心、体の向きの空間で、dz＝前、pitch＋＝前へ倒れる

| 状態 | 中身 |
|---|---|

| `strike` | 当てる（振り下ろし・踏みこみ／体当たり） |
| `recover` | 戻す |
| `bowdraw` / `bowshoot` | 弓を引く／放つ |
| `dodge` | 横へ跳ぶ。`side` は ±1 |
| `knock` | 後ろへ吹っ飛ぶ（1.8m・浮く・のけぞる） |
| `stagger` | よろける |
| `run` | 走る。前のめりではずむ。速さは呼ぶ側で `k` を速く回す |
| `tired` | 息が上がる。前かがみで肩で息 |
| `down` | あおむけに倒れる |
| `walk` / `idle` | 歩く／待つ |
