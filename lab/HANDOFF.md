## 2026-11-28 夜中（企画チャットより）：FROM_JISSO.md の頼み4つへの返事

**見方**：https://denmochan.github.io/dungeon/lab/?gallery で「図鑑」が開く。全部の魔物と勇者の3Dを、下のボタンでポーズを切りかえて見られる（◀▶で種族、指でなぞると回る）。`?gallery&auto` は自動でめぐる（撮影用）

### 1. 武器の持ちかえ（剣・弓・杖）
- 魔物（試し場の `window.__labMonDraw`）は **`a.role` が `"bow"` か `"snipe"` なら弓、それ以外は剣**
- 魔法の種族（本番の `MAGIC_SP30` と同じ式）は **杖**
- 弓：左手で持つ木の弓（革の握り・角の弓はず・弦）。「弓を引く」ポーズでは、弦を右手まで引いて矢をつがえる
- 勇者は職業の武器を形に焼きこんである（戦士＝剣と盾、騎士＝剣と盾、盗賊＝短剣、狩人＝弓、魔法使い・僧侶＝杖）
  - 焼きこんだ武器は、役目が弓のときと、掘るときに隠れる
- 作っている所：`function monTool`（`kind` が `"sword"` `"dagger"` `"bow"` `"staff"` `"pick"`、盾は `q.shield`）と、何を持たせるかを決める `weaponPlan`
- 追記（同じ夜）：勇者の武器も、ゴブリンと同じ作りこんだものに持ちかえた
  - 剣（戦士・騎士など）、短剣（盗賊）、杖（魔法使い・僧侶。玉の色は職で変える）、弓（狩人）
  - 盾（戦士・騎士）：木の板に鉄のふちと鉄の玉。騎士は青地に白い十字
  - 焼きこんだ武器は、持ちかえる手の分だけ隠す（`hideW`：4＝左手、6＝右手、1＝全部）
  - 倒れたときは武器を描かない

### 2. 戦闘のポーズ：`window.__labPose(種族, 状態, k, {side, t})`
- 戻り値は `{R, root}`
  - `R`：いつものリグ（`rigSp24` と同じ形）
  - `root`：体ごと動かす量 `{dx, dy, dz, pitch, roll}`。足もと中心、体の向きの空間で、dz＝前、pitch＋＝前へ倒れる
- `k` は 0〜1 の進み。長さ（秒）は呼ぶ側で決める（すばやさで振りかぶりを 0.2〜0.6 秒、など）

| 状態 | 中身 |
|---|---|
| `windup` | 振りかぶる。人の形はリグの slash の構えへ、足のない子は身をかがめて後ろへ |
| `strike` | 当てる（振り下ろし・踏みこみ／体当たり） |
| `recover` | 戻す |
| `bowdraw` / `bowshoot` | 弓を引く／放つ |
| `dodge` | 横へ跳ぶ。`side` は ±1 |
| `knock` | 後ろへ吹っ飛ぶ（1.8m・浮く・のけぞる） |
| `stagger` | よろける |
| `run` | 走る。前のめりではずむ。速さは呼ぶ側で `k` を速く回す |
| `tired` | 息が上がる。前かがみで肩で息 |
| `down` | あおむけに倒れる |
| `walk` / `idle` | 歩く／待つ |

- 試し場の魔物は `a.bst`（状態）と `a.bk`（k）を入れると、そのポーズで描く
- ポーズと root のかけ方：`window.__labPose` と `drawSkin` の最後（`root・向き・大きさ・位置をまとめてかける`）

### 3. 体の大きさ（人間＝1）
- 本番 `BODY30V2`・`HEROBODY30` の「大」を、試し場の `SIZE30` に写した
- 3Dの大きさ ＝ 大 × 1.82 ÷ その形の「背の高さ（横に長い子は長さ×0.55 のほうが大きければそれ）」。1.82 は人間の形の背の高さ
- 例：ゴブリン 0.7 → 人間の 7 割の背
- 武器は大きいまま（体の比率には入れていない）
- 前の大きさ（2Dの絵に合わせた大きさ）に戻すときは `window.__labOldSize=true`

### 4. 小物の位置と半径：`window.__labPropList[部屋番号]`
- 形は `[{k:"barrel", x, z, zw, r}, …]`
  - x・z は部屋の中の座標（本番の `props` と同じ）、zw は世界の z
  - r は、その形の高さ 0.12〜2.2m の部分の 9 割が入る円
- 入っているもの：置き物ぜんぶ（樽・木箱・宝箱・トロッコ・石像・水晶・つるはし・骨など）、鉱脈（`vein`）、壁ぎわの丸い岩（`boulder`）
- 作っている所：`function propMesh` の `addPR`、`window.__labProps3` の `RK`
- 線路・小石（高さ 0.12m 未満）は円に入れていない。上を歩ける

### そのほか
- 全種族の3Dの形：`lab/mon_<種族>.bin.gz`（できた順に足している）
  - 形式 `GB01`：人の形。骨13本
  - 形式 `GB1W`：人の形で、武器を焼きこんだもの。最後に頂点ごとの「武器なら1」がつく
  - 形式 `GB02`：人の形でない子。近い関節2つについて動き、頭は HR で回る
- 重さ：全部で約38MB。勇者は1体 約600〜850KB（髪と服が細かい）
  - **軽い版**：`lab/lite/`（約18MB、`?lite` で切りかえ）。形式 `GB03`：位置は0.5mm刻みの差分、面の番号は可変長
  - 作り方：近い頂点をまとめる方法（`lab/tools/lite.py`）
  - **まだ下書き**：ドラゴンの翼のような薄い所に筋が出る。本番に入れる前に、ちゃんとした減らし方（QEM）に替える必要がある
- 全種族そろった（74種）。図鑑で全部見られる

## 決まった方針（本人確認済み）

- **一番いい要素に全体を合わせる**：基準は3Dのゴブリン（丸い形・黒い輪郭線・3段のアニメ塗り）
- **絵柄をそろえるのが最優先**：リアルさやザラザラした質感は入れない（本人「きもい」）
- **壁は「新・岩の塊」**：丸くふくらんだ岩の積み重なり。線は細く、ぼかして、途切れさせる。天井・床も同じ描き方（床は線なし・色むらだけ）
- **壁と天井のつなぎ目は丸める**（天井が「ふた」に見えないように）
- **小物・魔物もゴブリンと同じ描き方**（トゥーン＋輪郭線、丸い形）
- **看板はいらない**
- **鉱石（水晶の群れ）は多すぎる**ので減らす

## 取り込むときの注意

- **看板**：タップで部屋の画面を開く入口でもある。消すなら、部屋の画面をどこから開くか（画面のボタンなど）を先に決めること
- **水晶を減らす**：試し場は見た目だけ間引いている。当たり判定（R.G）はそのまま。本番では部屋の中身を作る所で数を減らすこと
- **重さ**：魔物1種類で約300KB。種族が増える前に形を軽くする作業が要る
- **魔物の3D**：このセーブにいた3種類だけ。ほかの種族はまだ2Dの絵

## 魔物を3Dにする手順（`lab/tools/`）

1. リポジトリの一番上で `python3 -m http.server 8777` を起動する
2. `cd lab/tools && python3 extract2.py <種族名>` を実行する（ゲームの形をそのまま3Dの網にする）
3. `python3 skin2.py <種族名> && gzip -9 ../mon_<種族名>.bin` を実行する（骨と重みをつける）
4. `index.html` の `MON3` に種族名を足す

- 必要なもの：Playwright、Chrome（`--use-angle=swiftshader`）、scikit-image
- 人の形の種族（goblin・skeleton・orc・kobold・imp・golem・human）は、このままで動く
- 形のちがう種族（狼・コウモリなど）は、スライムのように動かし方を個別に作る必要がある
