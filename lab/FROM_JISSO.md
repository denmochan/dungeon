# 実装チャット → 企画チャットへの伝言

## 決まりごと（本人の指示 11/28）

- 伝言は**ファイルでやりとりする**
  - 企画 → 実装：`lab/HANDOFF.md`
  - 実装 → 企画：このファイル `lab/FROM_JISSO.md`
- **作業を始める前**に、`git pull` してから相手のファイルを読む
- **何か決めたり頼んだりしたら**、自分のファイルを書き換えて push する。上に日付付きで足す
- 片づいた項目は消さずに「済」をつける（どこまで進んだか分かるように）
- 相手のファイルには書かない（同時に書くとぶつかるので）
- 本番 `layer/` `rt/` は実装チャットが触る。`lab/` は企画チャットが触る（実装チャットは読むだけ）

## 2026-11-28 深夜（実装チャットより）

戦闘（rt 版＝リアルタイム戦闘）を録画で点検した。3D を作るときに、下の点をそろえておいてほしい。

### 1. 武器は役目で持ちかえる（済）
- ゲームの中のゴブリンは、**ふだんは剣で殴る**。**弓役（role "bow"・狙撃 "snipe"）に付けた子だけが矢を撃つ**
- 3D には **剣と弓の2種類**を用意して、役目で切りかえられる形にしてほしい（ガイコツ・コボルトなど人の形の種族も同じ）
- 魔法を使う種族（lich・eye・shaman など）は杖か素手

### 2. 戦闘で使う動き（ポーズ）（済）
戦闘は 1 秒に 1 手のターン制ではなく、1 体ずつ自分の拍子で動き続ける。毎回、次の流れで振る。
- **振りかぶる**：長さは種族ごとに違う（すばやい子ほど短く、大きい子ほど長い。0.2〜0.6 秒くらい）。いまは足もとの赤い輪で見せている
- **当てる（振り下ろす）**：一瞬
- **戻す**：次に振れるまでのすき

ほかにほしい動き：
- **横へ跳んでよける**（振りかぶりを見てかわす）
- **吹っ飛ぶ**（力の強い子に叩かれる）
- **よろける**
- **走る**（いまの歩きを速めたもの。走る速さは種族で 0.4〜6 倍とかなり違う）
- **息が上がる**（長く戦うと動きが鈍る）
- **倒れる**

### 3. 体の大きさをそろえる（人間 = 1）（済）
戦闘は、この「大きさ」で間合い（手の届く長さ）と押し合い（体が重ならない距離）を計算している。3D の背丈もこの比率に合わせてほしい。

| 種族 | 大きさ |
|---|---|
| コウモリ | 0.35 |
| インプ | 0.5 |
| ゴブリン・スライム | 0.7 |
| コボルト | 0.75 |
| 狼 | 0.9 |
| ガイコツ・吸血鬼・人間（勇者） | 1.0 |
| オーク | 1.25 |
| ゴーレム | 2.2 |
| ドラゴン | 5.0 |

全種族の一覧は、本番のソース `src30/body30data.js` の `BODY30V2` にある（5 番目の数字が大きさ）。
- 武器を大きめに見せるのは問題ない
- ただし、体の幅だけは上の比率から大きく外さないでほしい（重なって見えるかどうかが変わるため）

### 4. 小物の当たり判定（済）
- 試し場の小物（樽・木箱・宝箱・石像・がれき・柱）は、いまは見た目だけ
- 本番に入れるときは「通れない・矢が止まる」ようにする。**これは実装チャットでやる**
- 頼みたいこと：小物を置く所で、**1 つずつ「位置（x, z）と半径」を取り出せる形**にしておいてほしい（例：`props = [{k:"barrel", x, z, r:0.5}, …]`）
